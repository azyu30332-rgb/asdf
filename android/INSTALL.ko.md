# 안드로이드에서 책장 사용하기

앱은 Android 8.0 이상에서 실행하도록 제작했습니다. Play 스토어 계정이나 GitHub Pages는 필요하지 않습니다.

## 설치 파일 받기

이 대화의 작업 공간 경로는 다운로드 주소가 아닙니다. GitHub 업로드를 승인하고 실제 빌드가 완료된 후 아래 방법으로 받을 수 있습니다. 현재 파일이 GitHub에 올라갔다고 가정하지 마세요.

1. 휴대폰 브라우저에서 본인의 GitHub 저장소에 로그인합니다.
2. 저장소의 **Actions → Build Android APK**에서 성공한 실행을 엽니다.
3. **Artifacts → chaekjang-android-debug**를 다운로드합니다.
4. 휴대폰 파일 앱에서 ZIP 압축을 풀고 `app-debug.apk`를 엽니다.
5. 설치 화면에서 필요할 때만 해당 파일 앱의 **이 출처 허용**을 켭니다. 설치 후 다시 꺼도 앱 사용에 지장이 없습니다.
6. 홈 화면 또는 앱 목록의 **책장**을 엽니다.

이는 개인 테스트용으로 서명된 APK입니다. Play 스토어 배포나 실제 휴대폰 동작 검증은 별도입니다. 운영체제의 보안 검사 자체를 끄지 마세요.

## 사용과 데이터

- **만화책 등록**에서 제목·시작 권·마지막 권을 입력하면 한 번에 등록됩니다. 없는 권은 `3, 7-9`처럼 제외합니다.
- 시리즈를 눌러 판매할 권을 선택하고 **거래중**을 적용합니다. 해당 시리즈는 목록 맨 위로 올라옵니다.
- 거래가 끝나면 선택한 권을 **거래완료**로 변경합니다.
- 책의 위치·상태·거래 약속은 메모에 기록합니다.
- **백업**으로 JSON 파일을 원하는 위치에 저장하고, **복원**으로 다시 불러옵니다.
- **샘플 둘러보기**는 실제 목록을 바꾸지 않으며 샘플 변경은 저장되지 않습니다.

데이터는 이 앱이 설치된 휴대폰에만 저장되며 자동으로 다른 기기나 중고나라와 동기화되지 않습니다. 앱 삭제, 앱 데이터 초기화, 기기 변경 전에 꼭 백업하세요.

앱 업데이트는 동일한 서명 키로 만든 APK가 필요합니다. 현재 GitHub 빌드는 개인 테스트 키를 캐시에 보존하지만 캐시 유실 시 동일 키를 보장할 수 없습니다. 서명 불일치로 설치되지 않으면 기존 앱을 바로 삭제하지 말고 먼저 기존 앱에서 JSON 백업을 만드세요. 장기간 배포에는 관리되는 별도 릴리스 서명 키가 필요합니다.


## v1.1.0 업데이트 설치와 새 기능

기존 책장을 삭제하지 말고 새 APK를 열어 업데이트 설치하세요. 앱 ID는 동일하며 GitHub 빌드는 기존 테스트 서명 키를 캐시에서 재사용합니다. 서명 불일치가 발생하면 먼저 알려주세요. 데이터를 보존하려면 기존 앱을 삭제하지 않아야 합니다.

- 상단 ◐: 네 가지 색깔 테마 선택. 다크 테마도 포함됩니다.
- 만화책 등록 또는 시리즈 상세: 사진 찍기/사진 선택. 상세에서 바꾼 사진은 사진·메모 저장 버튼으로 반영합니다.
- 거래완료로 변경: 완료 날짜를 지정합니다. 오래된 판매일은 자동으로 바뀌지 않습니다. 수정하려면 판매일도 수정 체크를 선택하세요.
- 백업 → 휴대폰·Drive에 파일 저장: 파일 선택 창의 저장 위치를 선택합니다. 왼쪽 메뉴에서 Drive가 보이면 선택할 수 있습니다.
- 백업 → Google Drive 등에 공유: 공유 앱 목록에서 Drive를 선택해 업로드합니다. Drive 앱 설치와 로그인이 필요할 수 있습니다. 업로드 성공 여부는 선택한 앱에서 확인하세요.
- 복원: 휴대폰이나 Drive에서 JSON 파일을 선택하고 목록 교체를 확인합니다. 사진과 날짜도 함께 복원합니다.

현재 백업은 버전 2로, 구버전 1.0 앱에서는 복원할 수 없습니다. 업데이트는 기존 목록을 새 저장 방식으로 자동 복사합니다. 예전 데이터에 거래완료일이 없으면 판매일 미기록으로 보이며, 알맞은 날짜를 직접 넣을 수 있습니다.
