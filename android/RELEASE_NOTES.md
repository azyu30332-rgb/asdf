### 설치 방법

아래 Assets에서 `chaekjang-1.6.0.apk`를 누르고, 다운로드가 끝나면 그 파일을 열어 설치하세요. `Source code` ZIP은 설치 파일이 아닙니다.

이전의 `app-debug.apk`와 이름이 다릅니다. 새 버전은 화면 상단에 **v1.6.0**이 항상 표시됩니다. 이미 앱이 설치되어 있다면 삭제하지 말고 업데이트 설치하세요. 기존 목록은 보존하도록 구성했습니다.

### 이전 버전에서 설치가 거부되는 경우

기존 배포본의 서명이 버전마다 달라진 문제가 확인되어, v1.3.1부터 사용하는 키 경로를 고정하고 APK의 서명 일치를 검증합니다. "기존 패키지와 충돌" 등으로 업데이트 설치가 거부되면 반드시 기존 앱에서 백업 파일을 휴대폰이나 Drive에 저장한 뒤 앱을 삭제하고 새 버전을 설치하여 복원하세요. 백업 전에는 앱을 삭제하지 마세요.

### 이번 변경

- 원본을 유지하는 사진 자르기·좌우 회전 및 편집본 추가 저장
- 폴더 만들기·이름 변경·삭제, 폴더별 보기, 책 등록·상세에서 폴더 이동
- 폴더 삭제 시 책과 사진은 미분류로 이동, 빈 폴더도 백업·복원
- 엑셀·CSV 문서에 폴더 열 추가

- 책 한 시리즈에 판매 사진 최대 12장 보관, 여러 장 선택·촬영 지원
- 새 사진은 최대 1,600px JPEG로 압축, 기존 표지 사진은 그대로 사진 목록에 유지
- 상세 화면에서 사진 추가·표지 지정·삭제를 즉시 저장
- 사진 크게 보기, 선택한 사진 갤러리 저장 및 여러 장 한 번에 공유
- Android 10 이상은 갤러리 Pictures/책장 폴더에 저장, 이전 Android는 저장할 폴더 선택
- 사진 전체를 포함하는 버전 3 JSON 백업, 이전 버전 백업도 지원
- 직전 배포 버전에 사진·내용을 저장한 뒤 새 APK를 덮어 설치하는 사진·데이터 보존 검사 추가

앱을 삭제하지 말고 업데이트 설치하세요. 사진은 앱 내부에 복사되며 갤러리 원본은 자동으로 삭제하지 않습니다. 새 사진은 저장 공간을 줄인 판매용 사본이며 원본 해상도 그대로의 보관은 아닙니다. 갤러리를 정리하기 전 앱의 사진을 다시 열어 확인하고 사진 포함 JSON 백업도 별도로 보관하세요.

### 포함된 기능

- 글씨와 등록 버튼 확대, 여백 축소
- 사진 촬영·갤러리 표지 등록
- 등록일·권별 거래완료일
- 숲빛·크림·블루·다크 테마
- 사진·날짜를 포함한 휴대폰 백업·복원, 외부 Drive 앱 공유

개인 사용을 위한 테스트 서명 APK입니다. Google Drive 업로드는 파일 선택 창이나 공유 앱에서 직접 진행하며 Drive 앱 설치와 로그인이 필요할 수 있습니다. 앱 데이터는 휴대폰에 저장되므로 삭제 전 백업해 주세요.
