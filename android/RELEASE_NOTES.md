### 설치 방법

아래 Assets에서 `chaekjang-1.5.0.apk`를 누르고, 다운로드가 끝나면 그 파일을 열어 설치하세요. `Source code` ZIP은 설치 파일이 아닙니다.

이전의 `app-debug.apk`와 이름이 다릅니다. 새 버전은 화면 상단에 **v1.5.0**이 항상 표시됩니다. 이미 앱이 설치되어 있다면 삭제하지 말고 업데이트 설치하세요. 기존 목록은 보존하도록 구성했습니다.

### 이전 버전에서 설치가 거부되는 경우

기존 배포본의 서명이 버전마다 달라진 문제가 확인되어, v1.3.1부터 사용하는 키 경로를 고정하고 APK의 서명 일치를 검증합니다. "기존 패키지와 충돌" 등으로 업데이트 설치가 거부되면 반드시 기존 앱에서 백업 파일을 휴대폰이나 Drive에 저장한 뒤 앱을 삭제하고 새 버전을 설치하여 복원하세요. 백업 전에는 앱을 삭제하지 마세요.

### 이번 변경

- 컬렉션 옆 엑셀 내보내기 버튼 추가
- XLSX: 시리즈 요약·권별 상세 시트를 한 파일로 저장
- CSV: 시리즈 요약 또는 권별 상세를 선택하여 저장
- 제목·작가·권수·보유/거래/미보유 상태·메모·등록일·판매일 포함
- 휴대폰·Google Drive에 파일 저장 또는 공유
- 문서는 확인·편집용이며, 사진 포함 복원은 기존 JSON 백업을 이용

### 포함된 기능

- 글씨와 등록 버튼 확대, 여백 축소
- 사진 촬영·갤러리 표지 등록
- 등록일·권별 거래완료일
- 숲빛·크림·블루·다크 테마
- 사진·날짜를 포함한 휴대폰 백업·복원, 외부 Drive 앱 공유

개인 사용을 위한 테스트 서명 APK입니다. Google Drive 업로드는 파일 선택 창이나 공유 앱에서 직접 진행하며 Drive 앱 설치와 로그인이 필요할 수 있습니다. 앱 데이터는 휴대폰에 저장되므로 삭제 전 백업해 주세요.
