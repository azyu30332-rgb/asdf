# 책장 — 개인 만화 컬렉션

시리즈별 만화책 등록, 빠른 검색, 권별 보유/거래 상태와 개인 메모를 관리하는 한국어 웹사이트입니다.

## 실행

Python 3와 웹 브라우저만 있으면 됩니다. 패키지 설치가 필요 없습니다.

```sh
cd /workspace/asdf
npm start
```

기본 포트는 3000입니다. HTML, CSS, JavaScript 정적 파일이므로 정적 호스팅에도 배포할 수 있습니다. `index.html`을 파일로 직접 열지 말고 HTTP 서버로 실행하세요.

## 사용

- **만화책 등록**: 제목, 작가, 시작/마지막 권, 빠진 권(예: `3, 7-9`), 상태와 메모를 입력합니다. 최대 5,000권씩 등록할 수 있습니다.
- **상세 보기**: 권을 선택해 일부 또는 전체 권의 상태를 변경하거나 메모를 저장합니다.
- **검색**: 제목, 작가, 권수(`31권`), 메모로 검색합니다. 거래중인 시리즈가 항상 우선 표시됩니다. 페이지당 12개 시리즈를 표시합니다.
- **백업/복원**: JSON 파일로 백업합니다. 복원은 확인 후 기존 목록 전체를 교체합니다.
- **샘플 둘러보기**: 샘플 변경은 저장되지 않습니다. 내 컬렉션으로 돌아가면 원래 데이터를 표시합니다.

목록과 사진은 접속한 브라우저의 IndexedDB에, 테마 선택은 localStorage에 저장됩니다. 계정이나 서버 동기화는 없으며 브라우저 데이터 삭제, 시크릿 모드 종료 또는 사이트 주소 변경 시 접근할 수 없으므로 정기적으로 백업하세요. 중고나라에 자동 연동하지 않으며 거래 상태는 직접 관리합니다. 공용 컴퓨터 사용에 주의하세요. 외부 글꼴을 불러오지 못해도 시스템 글꼴로 동작합니다.

## 검증

```sh
npm test
```

일괄 등록, 권수 검증, 거래중 우선 정렬, 검색, 백업 검증 및 3,000권 처리에 관한 테스트를 실행합니다.

## Android 앱

Android 8.0 이상을 대상으로 하는 독립 실행 앱입니다. 앱 안에 웹 화면이 포함되며 인터넷/웹 서버/GitHub Pages가 필요하지 않습니다. 저장된 목록은 앱 전용 WebView의 IndexedDB에 보관합니다. 앱 삭제/앱 데이터 초기화 시 삭제되므로 앱의 백업 버튼으로 JSON을 휴대폰 파일에 보관하세요. 복원 시 기존 목록을 교체하기 전에 확인합니다. 인터넷·계정·전체 저장소 접근 권한을 요청하지 않습니다.

빌드에는 Node.js, JDK 17 이상(현재 JDK 21), Android SDK Platform 35 및 Build Tools 35.0.0, Gradle 8.11.1이 필요합니다.

```sh
cd android
./gradlew assembleDebug lintDebug
```

산출물: `android/app/build/outputs/apk/debug/app-debug.apk`. 이 APK는 개인 테스트용 디버그 서명 빌드이며 Play 스토어에 게시하지 않습니다. 휴대폰에 파일을 전달한 뒤 설치 파일을 열어 설치합니다. 해당 파일을 여는 앱에 한해서만 '이 출처 허용'이 필요할 수 있습니다. 설치 후 앱은 인터넷 없이 작동합니다. 업데이트 시 동일한 서명 키가 필요하므로 디버그 키를 잃으면 업데이트 설치가 불가능할 수 있습니다. 배포용 서명과 APK 전달은 별도 절차입니다.

기존 HTML을 수정하면 Gradle 빌드가 단일 HTML을 생성하여 앱 assets에 자동으로 포함합니다. 웹 UI만 생성하려면 `node build-standalone.mjs`를 실행합니다.


## v1.1.0 업데이트

- 휴대폰 글씨와 버튼을 키우고, 중복된 상단 제목 영역과 요약 박스 사이의 여백을 줄였습니다.
- 상단 ◐ 버튼에서 숲빛·따뜻한 크림·차분한 블루·다크 중 하나를 선택할 수 있습니다. 테마 선택은 기기에 유지됩니다.
- 등록/상세 화면에서 사진 촬영 또는 갤러리 선택으로 시리즈 표지를 바꿉니다. 원본은 변경하지 않고 앱에는 압축한 작은 JPG 썸네일만 저장합니다.
- 등록일과 권별 거래완료일을 기록합니다. 기존 판매일을 유지하며, 날짜 수정 체크를 선택하면 수정할 수 있습니다. 예전 판매 기록에 날짜가 없으면 미기록으로 표시합니다.
- 사진을 저장하기 위해 목록을 IndexedDB로 옮겼습니다. 이전 localStorage 목록은 성공적으로 복사한 뒤에도 원본을 남겨두며, 기존 버전 1 백업을 계속 읽습니다. 새 버전 2 백업은 사진과 날짜를 포함하며 최대 128MB를 지원합니다. 1.0 앱은 새 백업 형식을 읽을 수 없습니다.
- 백업 버튼은 샘플 보기에서도 실제 내 컬렉션을 백업합니다. 휴대폰·Drive 파일 저장 또는 Google Drive 등으로 공유를 선택할 수 있습니다. Drive 앱과 해당 계정 로그인이 필요할 수 있으며 업로드 완료는 Drive에서 확인합니다. 자동 동기화나 앱 자체의 Google 계정 연결은 구현하지 않습니다.
- Android 문서 선택 창으로 실제 JSON 읽기/쓰기, 카메라 취소 후 재시도, 사진의 압축/영속성, Drive 공유 창 호출을 검증하는 기기 테스트가 추가되었습니다. GitHub 빌드에서는 Android 35 에뮬레이터에서 실행하고 성공 후 APK를 업로드합니다.

검증: `npm test`, `python3 tests/browser_smoke.py` (개발 서버와 Playwright/Chromium 필요), Android의 `assembleDebug lintDebug connectedDebugAndroidTest`. 브라우저 검증 스크립트는 로컬 CDP 포트 9222의 테스트용 Chromium을 사용합니다. 실제 카메라 앱의 촬영이나 Drive 서버에 대한 업로드는 사용 기기에서 확인해야 합니다.
